# Scene artwork prompt manifest

## Generation mode

The ten direct-iPad scene assets were generated with the built-in image-generation
mode. The user's first attached story image was supplied as a style reference only,
not as an edit target. Every resulting scene is an original composition.

## Shared prompt

Use case: illustration-story.

Asset type: production hidden-object game scene for children ages 3–5 on iPad.

Create a completely original scene and original characters. Use a polished 2D
children's picture-book treatment with clean confident outlines, softly modeled
shapes, believable anatomy and perspective, gentle material texture, layered depth,
and vivid but soothing colors. The result should be more realistic and detailed than
flat clip art while remaining warm and cartoonish.

Use a single 3:2 landscape scene, eye-level wide view, full-bleed, with a balanced
natural storytelling composition. Every named target must appear fully recognizable,
separated from other targets, and large enough to identify on an iPad. Integrate the
objects naturally rather than presenting a grid.

Keep the atmosphere cheerful and caring with friendly expressions, inclusive
original children, and no peril. Do not include written words, letters, numbers,
signs, labels, UI, borders, logos, trademarks, or watermarks.
