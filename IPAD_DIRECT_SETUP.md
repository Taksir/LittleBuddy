# Run Ask & Find directly on an iPad

The iPad-compatible package is [AskAndFind.swiftpm](AskAndFind.swiftpm). It runs in
Apple's free Swift Playgrounds app and does not need a Mac.

1. Install **Swift Playgrounds** from the App Store.
2. Visit `https://github.com/Taksir/Littlebuddy` in Safari.
3. Choose **Code → Download ZIP**.
4. Extract the ZIP in the Files app.
5. In Swift Playgrounds, tap **Browse**.
6. Select the extracted `AskAndFind.swiftpm` package.
7. Let it compile, then tap **Run App**.

Requirements: iPadOS 17 or newer and enough free storage for Swift Playgrounds. The
first compilation can take longer than subsequent launches.

The app runs full screen through Swift Playgrounds. A normal independently installed
home-screen/App Store build remains a separate distribution step.
